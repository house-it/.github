# 🏠 하우스잇 (House it)
![house-it](https://github.com/user-attachments/assets/018700b2-b06b-4a3d-a3b9-bf66a4ab331a)

> **“독립은 생존이 아니라, 성장의 과정이어야 합니다.”**

대한민국 20대 청년의 **81%가 아직 부모님과 함께 살고 있다**는 사실 알고 계셨나요?
높은 집값과 불안정한 일자리 탓에 청년들의 ‘진짜 독립’은 점점 더 어려워지고 있습니다.
그 결과, 전세 계약서 검토부터 공과금 관리, 집 수리, 청소 같은 **기본적인 생활 역량조차 직접 배울 기회가 부족**한 현실입니다.

하우스잇은 이런 문제의식에서 시작됐습니다.
학교나 포털에서는 알려주지 않는 현실적인 생활 문제를 청년들이 **직접 묻고 배우며 해결할 수 있는** 플랫폼입니다.
